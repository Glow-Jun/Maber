# Maber v0.2.0 实施计划

> **For agentic workers:** 按任务顺序执行，每个 Task 完成即测试 + 提交。步骤用 `- [ ]` 跟踪。

**Goal:** 交付 Maber v0.2.0——Total Mode 完整面板（大纲 / 最近文件 / 语法速查 / 设置入口）+ 主题与排版设置（跟随系统 / 浅色 / 深色，字体、字号、行高、阅读宽度），并保持 Slim Mode 的极简体验不变。

**Tech Stack:** .NET 10 / WinUI 3 / Windows App SDK 1.8+ / WebView2；TypeScript + esbuild + vitest；xunit。

**规约：** conventional commits；每任务结束即提交；消息协议字段以 `types.ts` / `BridgeMessages.cs` 双侧对齐。

## 0. 现状基线（v0.1.1）

- 入口：`App.OnLaunched` 直接 `new MainWindow()`；`MainWindow` 从命令行参数取首个存在的文件路径。
- 布局：`MainWindow.xaml` 两行（标题栏 36px + WebView2），大纲/查找为 `Popup`，`Ctrl+K` 只弹大纲。
- 大纲数据：Web 经 `outlineChanged` 上报 `_outline`（level/text/line），`Ctrl+K` 时临时填充 ListView。
- 主题：`SendTheme()` 每次读注册表 `AppsUseLightTheme`，只区分 light/dark，无用户偏好。
- 排版：全部写死在 `app.css`（`#content { max-width:46rem; font:16px/1.75 ... }`）。
- Core：仅 `EncodingDetector` / `FileDocumentService` / `ExternalFileWatcher`，无设置与最近文件。
- 无「模式」概念：双击文件与直接启动走同一个 `MainWindow`。

**本版边界（明确不做）：** 多标签、wikilink 跨文件解析、LaTeX 公式辅助器、MSIX 打包、自定义配色、最近文件右键管理（仅自动剔除不存在的项）。

## 1. 设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 模式判定 | 命令行带可读文件 → Slim；无文件 → Total | 与设计文档「双击进 Slim、直接启动进 Total」一致 |
| Total 侧栏 | 左侧 240px 固定栏，可折叠（`Ctrl+B`） | 不引入 NavigationView，保持轻量自绘 |
| 侧栏分区 | 大纲 / 最近 / 速查 三段切换 + 底部设置按钮 | 一屏一栏，避免多层导航 |
| 设置入口 | Total Mode 底部按钮 → `ContentDialog` | 参数少，对话框比独立设置页省一层导航 |
| 设置作用域 | 全局单文件，所有窗口共享、实时广播 | 多窗口（wikilink 新窗口）一致 |
| 设置落盘 | `%LOCALAPPDATA%\Maber\settings.json` | 不污染笔记库；卸载可整体清理 |
| 字体 | 预设键（default/yahei/simsun/kaiti/mono），不开放自由输入 | 避免无效字体名与 CSS 注入面 |
| 排版下发 | 宿主发数值/键名，Web 映射为 CSS 变量 | 渲染细节留在内核，协议保持简单 |
| 最近文件 | 最多 20 条，路径去重（忽略大小写），加载时剔除不存在项 | 无 vault 概念下的最小可用实现 |
| 主题 | 偏好 system/light/dark；system 时读注册表 | 保留现有跟随系统行为，新增覆盖能力 |

**设置项与默认值：**

| 字段 | 类型 | 默认 | 范围 / 取值 |
|---|---|---|---|
| `theme` | string | `system` | `system` / `light` / `dark` |
| `fontFamily` | string | `default` | `default` / `yahei` / `simsun` / `kaiti` / `mono` |
| `fontSize` | double | `16` | 12–24 |
| `lineHeight` | double | `1.75` | 1.4–2.2 |
| `contentWidth` | double | `46` | 30–70（单位 rem） |
| `recentFiles` | string[] | `[]` | 最多 20，绝对路径 |

**消息协议新增（宿主 → Web）：**

```ts
| { type: "setTypography"; fontFamily: string; fontSize: number; lineHeight: number; contentWidth: number }
```

```csharp
public static List<string> NormalizeRecent(IEnumerable<string> paths)
{
    var seen = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
    var list = new List<string>();
    foreach (var raw in paths)
    {
        if (string.IsNullOrWhiteSpace(raw)) continue;
        string full;
        try { full = Path.GetFullPath(raw); } catch { continue; }
        if (!File.Exists(full) || !seen.Add(full)) continue;
        list.Add(full);
        if (list.Count == 20) break;
    }
    return list;
}
```

```csharp
using System.Text.Json;

namespace Maber.Core;

public sealed class SettingsStore
{
    private static readonly JsonSerializerOptions JsonOpts = new(JsonSerializerDefaults.Web)
    {
        WriteIndented = true,
    };

    public string FilePath { get; }

    public SettingsStore(string? path = null) => FilePath = path ?? Path.Combine(
        Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "Maber", "settings.json");

    /// <summary>文件缺失、JSON 损坏、字段越界都不抛异常，统一回落到默认值</summary>
    public AppSettings Load()
    {
        try
        {
            if (!File.Exists(FilePath)) return new AppSettings();
            var json = File.ReadAllText(FilePath);
            return (JsonSerializer.Deserialize<AppSettings>(json, JsonOpts) ?? new AppSettings()).Normalize();
        }
        catch { return new AppSettings(); }
    }

    /// <summary>临时文件 + 替换，避免写一半留下坏 JSON</summary>
    public void Save(AppSettings settings)
    {
        var dir = Path.GetDirectoryName(FilePath)!;
        Directory.CreateDirectory(dir);
        var tmp = Path.Combine(dir, $".settings.{Guid.NewGuid():N}.tmp");
        File.WriteAllText(tmp, JsonSerializer.Serialize(settings.Normalize(), JsonOpts));
        try { File.Move(tmp, FilePath, overwrite: true); }
        finally { try { if (File.Exists(tmp)) File.Delete(tmp); } catch (IOException) { } }
    }
}
```

```csharp
using Maber.Core;

namespace Maber.App;

/// <summary>应用级设置单例：所有窗口共享同一份内存状态与持久化入口。</summary>
public static class SettingsHost
{
    private static readonly SettingsStore Store = new();
    public static AppSettings Current { get; private set; } = Store.Load();

    /// <summary>任意窗口修改设置后调用；立即广播，磁盘写入由调用方去抖</summary>
    public static void Update(Func<AppSettings, AppSettings> change)
    {
        Current = change(Current).Normalize();
        Changed?.Invoke(null, EventArgs.Empty);
    }

    public static void Persist() => Store.Save(Current);

    /// <summary>记录最近文件：去重提前、剔除失效、上限 20，并落盘</summary>
    public static void RecordRecent(string path)
    {
        var next = new List<string> { path };
        next.AddRange(Current.RecentFiles);
        Current = (Current with { RecentFiles = AppSettings.NormalizeRecent(next) });
        Persist();
        Changed?.Invoke(null, EventArgs.Empty);
    }

    public static event EventHandler? Changed;
}
```

```ts
export interface TypographySettings {
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  contentWidth: number;
}

const FONT_STACKS: Record<string, string> = {
  default: `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif`,
  yahei: `"Microsoft YaHei", "Segoe UI", system-ui, sans-serif`,
  simsun: `SimSun, "Songti SC", serif`,
  kaiti: `KaiTi, "Kaiti SC", serif`,
  mono: `"Cascadia Code", Consolas, "Microsoft YaHei", monospace`,
};

/** 未知键回落 default；数值夹到与宿主一致的范围，避免异常设置打乱排版 */
export function typographyVars(t: TypographySettings): Record<string, string> {
  const size = Math.min(24, Math.max(12, Number(t.fontSize) || 16));
  const lh = Math.min(2.2, Math.max(1.4, Number(t.lineHeight) || 1.75));
  const width = Math.min(70, Math.max(30, Number(t.contentWidth) || 46));
  return {
    "--font-family": FONT_STACKS[t.fontFamily] ?? FONT_STACKS.default,
    "--font-size": `${size}px`,
    "--line-height": String(lh),
    "--content-width": `${width}rem`,
  };
}

export function applyTypography(t: TypographySettings) {
  const root = document.documentElement;
  for (const [k, v] of Object.entries(typographyVars(t))) root.style.setProperty(k, v);
}
```
